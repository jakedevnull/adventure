# Developing Everwyn

Everwyn is in the design stage — the repo currently holds design docs under [`design/`](design/), not runnable code. Start there to understand the game before building.

1. **Read the design.** Skim [`design/DESIGN.md`](design/DESIGN.md), [`design/UNIVERSE.md`](design/UNIVERSE.md), and [`design/WRITING-GUIDE.md`](design/WRITING-GUIDE.md) so your work fits the world and its style.
2. **Pick up an issue.** Track work in Linear and branch off `main` for each change.
3. **Open a PR.** Keep changes focused and reference the issue; a maintainer reviews before merge.
4. **Changing canon?** If a change touches core canon or adds world content others will depend on, file an [ERP](design/ERP.md) rather than an ordinary PR. Most content does not need one — see [ERP-0000 §1.1](design/ERP.md#11-when-to-file-one-and-when-not-to).

Build and run instructions will land here once the tech stack is chosen.
