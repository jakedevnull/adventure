# The ERP register

This directory holds Everwyn Revision Proposals — numbered proposals to change core canon
or to add world content that later work will depend on. The process is defined in
[ERP-0000](../ERP.md); read it first.

## Filing one

1. Check whether you even need an ERP. Most contributions do not — see
   [ERP-0000 §1.1](../ERP.md#11-when-to-file-one-and-when-not-to). Ordinary rooms, items, and
   small Threads go through normal review, not this register.
2. Copy [`TEMPLATE.md`](./TEMPLATE.md) to `NNNN-short-slug.md`, taking the next free number.
3. Fill in the front-matter and sections, then open a pull request.
4. The proposal is reviewed against the three gates (ERP-0000 §4). The decision is written back
   into the file's `Status` and a `Decision` note before merge.
